# Third-party and imported assets

## Analog Canvas device SVG export

The `assets/device-svg` directory is populated from the user-provided
`analog-canvas-device-svg-20261023` package.

- Source repository recorded by the package: `cascode-ai/analog-canvas`
- Source commit recorded by the package: `a239991de3d765ad68729a2fc59b87483c7d401c`
- Style profile recorded by the package: `razavi-textbook-v1`
- Package integrity values: see the preserved `SHA256SUMS` file

The export was generated from the public `cascode-ai/analog-canvas` repository,
which is distributed under AGPL-3.0-only. This repository applies the same
license to the combined work and distributes corresponding source alongside
binary releases. Per-file integrity values remain available in the packaged
`SHA256SUMS` file.
