# Analog Canvas device SVG export

This package contains every component appearance in the source catalog.

- `svg/<id>.svg`: the catalog entry's default appearance.
- `svg/variants/`: alternate or base appearances for symbols with variants.
- `manifest.json`: IDs, names, categories, pins, view boxes and file mappings.
- `catalog.csv`: compact tabular index for import tools.
- `index.html`: local visual index; open it in a browser.
- `SHA256SUMS`: file integrity hashes.
- `fonts/`: fonts used by the editor; SVGs retain SVG text for downstream editing.

Generated from a239991de3d765ad68729a2fc59b87483c7d401c. The SVG canvases are transparent and use the catalog's view boxes. Colors and strokes follow the `razavi-textbook-v1` profile.
